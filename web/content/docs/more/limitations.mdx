## Honest limits

- **Actionable, not important.** Triage decides whether a report is worth acting on, not how important it is. Every actionable report earns the same reward; severity stays with the team, through bonuses.
- **Recent duplicates only.** The judge sees the last 25 accepted reports, to keep the prompt small. A copy of an older report can be judged actionable and keeps its reward. That is the honest cost of a short prompt; the team can see the overlap in its queue.
- **Public reports.** Everything filed is on chain, so Triage is for product feedback, never for security vulnerabilities. Every scope should say where those go.
- **One verdict per report.** There is no appeal and no second judge on the same report. A tester who disagrees can file a clearer report, within the weekly cap and with a new stake.
- **Filing order.** Reports in a program are judged in the order they were filed. That is what stops a copy from being judged before its original, and it means a report waits for the ones filed before it. Anyone may ask the validators to judge the next one.
- **The scope is fixed.** It cannot change during a program; a new scope means a new program.
- **A model's reading.** Several validators must agree, but each one reads with a language model. A report that sits on a boundary, such as a real bug with no expected result, can go either way; the evaluation page publishes such cases as they came out.

## Limits the contract enforces

| Limit | Value |
|---|---|
| Program name | 80 characters, one line |
| Scope | 1,200 characters |
| Report title | 100 characters, one line |
| Report body | 1,500 characters |
| Report kinds | `bug`, `usability`, `idea` |
| Weekly cap per tester per program | 1 to 20, set by the team |
| Duration | 0 to 120 days; 0 opens a one-hour trial (3600 seconds) |
| First funding | at least one reward |
| Stake | exactly the program's stake, sent with `submit` |
| Accepted reports the judge sees | the last 25 |
| Summary stored from the leader | 120 characters, one line |
| Reason stored from the leader | 200 characters, one line |
| Page size of `list_reports` | 50 |
| Reports listed by `tester_stats` | the latest 50 |

A week is the contract's own: transaction time in seconds since 1970, divided by 604,800. It turns at 00:00 UTC on Thursdays, and every validator computes the same one.
